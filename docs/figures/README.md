# Figures

Figures from the paper, downscaled and colour-quantised for web display. The originals
are the vector-quality renders submitted with the manuscript.

| File | Shows | Used in |
|---|---|---|
| `pipeline.png` | method overview, data generation through to the composite map | README, method |
| `ray_augmentation.png` | ray-cone augmentation at increasing sector counts and widths | README, method |
| `qualitative.png` | completion, error and σ for one sample per held-out environment | README, results |
| `traversability.png` | partial input to uncertainty-gated traversability decision | README, traversability |

These are our own figures, released under CC BY 4.0 together with the rest of the
documentation (see `../../LICENSE-DATA`). They depict data derived from the TartanGround
dataset, which is itself CC BY 4.0 and must be cited alongside them.
